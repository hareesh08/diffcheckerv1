Quick start

  1. Upload two files — .xlsx, .xlsm, .csv, .tsv, or .txt.
  2. Pick a sheet per file and a match mode (header-based table or sequential rows).
  3. Run the comparison — files stream row by row into SQLite.
  4. Review changes, filter, and export as CSV or JSONL.

Options

  • Ignore whitespace — trim/collapse whitespace before comparing.
  • Ignore case — case-insensitive compare.
  • Header line — 1-based header row index (0 = no header).

Formats

  • CSV / TSV / TXT — streamed
  • XLSX / XLSM — streamed
  • XLS / XLSB / ODS — not yet supported

Privacy

Runs entirely on your machine. Files never leave your computer.
